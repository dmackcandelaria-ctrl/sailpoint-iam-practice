# SailPoint IAM Practice - Dmack

Practice portfolio for SailPoint Analyst role.
I track tickets in Jira, follow SOPs in Confluence, and execute in SailPoint.

## What is in this repo?
- JML Tracker - Joiner, Mover, Leaver process
- Correlation - How to identify Correlated vs Orphan accounts
- Ticket Tracker - Jira -> Confluence -> SailPoint -> AD -> Jira DONE

## JML Rule
- Joiner = CHECK MUNA (Verify Employee ID in Workday)
- Leaver = TANGGAL AGAD (Revoke FIRST, Verify LATER)
- Access Request = APPROVAL MUNA (Need Manager written approval in Jira)

## Tools
Jira = Ticketing | Confluence = SOP | SailPoint = Execution | AD / Workday = Target System
